# Movie Recommendation Ranking with CatBoost

Проект по персонализированному ранжированию (ranking) фильмов для пользователей.

## Overview

Цель проекта - построить модель, которая для пользователя ранжирует фильмы, которые он еще не смотрел, и поднимает выше те, котоыре с наибольшей вероятностью ему понравятся.

Задача рассматривается как **learning to rank**, а не как обычная классификация или регрессия.
Модель использует историю оценок пользователя, признаки фильмов и user-item признаки, чтобы сформировать top-K рекомендаций.

## Problem statement

Для каждого пользователя есть:
 - история просмотренных и оцененных фильмов;
 - оценки, по которым можно понять предпочтения пользователя;
 - множество фильмов, которые он еще не оценивал.

Надо:
 - сформировать набор фильмов-кандидатов;
 - вычислить признаки для каждоый пары `(user, movie)`;
 - обучить модель ранжировать (rank) кандидатов;
 - получить top-K рекомендаций для пользователя.

## Dataset

В источника данных используется **MovieLens**.

Планируемые датасеты:
 - `MovieLens 1M` для первой версии;
 - потом можно расширить до `MovieLens 25M`.

Основные таблицы:
 - `ratings` - оценки пользователей фильмам с временными метками;
 - `movies` - информация о фильмах и жанрах;
 - дополнительные таблицы могут использоваться, если потребуется расширение признаков.

## Data split strategy

Используется **разделение по времени**, чтобы исбежать leakage.

Логика:
 - ранняя история пользователя используется как input;
 - более поздние оценки используются как будущие взаимодействия;
 - модель должны по прошлому предсказать, какие фильмы окажутся релевантными в будущем.

## Target definition

Текущая логика:

 - **positive**: фильм, который пользователь оценил в будущем на `4` или `5`;
 - **negative**: фильм из набора кандидатов, который не стал позитивным примером.

## Two-phased pipeline

Ранжировать все фильмы для каждого пользователя неэффективно, поэтому используется двух-шаговый подход:

1. **Candidate generation**
   Формируется ограниченный набор фильмов-кандидатов.

2. **Ranking**
   `CatBoostRanker` сортирует кандидатов по вероятной релевантности.

## Features

Планируемые типы признаков (фич):

### User features
 - средняя оценка пользователя;
 - количество оцененных фильмов;
 - предпочитаемые жанры;
 - доля высоких оценок;
 - активность пользователя.

### Movie features
 - средняя оценка фильма;
 - популярность фильма;
 - количество оценок;
 - жанры;
 - год выпуска фильма.

### User-movie features
 - совпадение жанров фильма с предпочтениями пользователя;
 - отклонение популярности фильма от обычного профиля пользователя;
 - статистики взаимодействия пользователя с похожими фильмами;
 - признаки новизны и персонального соответствия.


## Model

Основная модель:
 - `CatBoostRanker`

Почему именно она:
 - удобна для ranking задач;
 - хорошо работает с табличными данными;
 - подходит для user-item признаков;

## Baselines

Планируется несколько baseline-подходов:

1. **Popularity baseline**
   Рекомендовать самые популярные фильмы.

2. **Genre preference baseline**
   Рекомендовать популярные фильмы предпочитаемых жанров пользователя.

3. **Pointwise baseline**
   классификация или регрессия для пары `(user, movie)` без явной ranking objective.

3. **CatBoostRanker**
   Основная ranking-модель.

## Evaluation and metrics

Планируемые метрики:
 - `NDCG@10` (основная, лучше отражает качество top-K рекомендаций, чем обычные classification-метрики)
 - `Recall@10`
 - `MRR`
